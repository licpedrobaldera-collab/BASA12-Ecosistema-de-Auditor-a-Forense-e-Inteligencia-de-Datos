# BASA HALLAZGOS INTELLIGENCE PRO

## Windows
Instale Python 3.11 o 3.12. En CMD dentro de esta carpeta:

python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py

El sistema se abre en el navegador local.
